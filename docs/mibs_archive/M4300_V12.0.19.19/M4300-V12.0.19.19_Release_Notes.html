Release Date:

February 12, 2026

 

Enhancements:

The AV UI provides the following enhancements:

  • Support for the Default profile with IGMP Plus enabled.
  • Updated the Data profile to disable IGMP.
  • Updated the Audio Basalte Multiroom profile to disable IGMP and MLD snooping.
  • Updated the Audio Dante profile to remove storm-control for broadcast traffic.
  • Updated the Lighting profile to remove storm-control for broadcast traffic.
  • Updated the G&D KVM-over-IP profile and applied MAC filtering on trunk and LAG interfaces.
  • Removed “cos queue strict” configuration from global QoS settings.
  • Updated the Main UI URL dynamically to follow the configured HTTP/HTTPS web protocol.
  • Changed the default AV UI color placeholder to #00FF00 when you create a new profile.

 

Bug Fixes:

This firmware addresses the following bugs:

  • Fixes the issue where power in and out of a fiber transceiver does not display through SNMP [CE-7134]
  • Fixes the issue where a crash occurs occasionally when ARP table is full. [CE-6958]
  • Fixes the issue where multicast entries are not remembered when MLD Plus is disabled on a VLAN. [MS-5040]
  • Fixes the issue where the Auto-Negotiation status does not display as ‘Enabled’ in AV UI if it is configured through the CLI. [MS-5156]
  • Fixes the issue where Auto-Negotiation status displays as ‘Unknown’ in AV UI when a cable is disconnected from the port. [MS-5155]
  • Fixes the issue where the Rest API script is rejected if you use the Linux platform. [CE-7454]
  • Fixes the issues where the Rest API token does not work after 24 hours. [CE-7418]
  • Fixes the issue where the Rest API is rejected with other admin users. [CE-7351]
  • Fixes the issue where the flow control does not display in the API response. [CE-7292]

 

Known Issues:

This AV UI contains the following known issues:

  • In stacking units, an AV UI profile on the primary management unit does not synchronize to member units. The profile on member units becomes a data profile.

Workaround: Create an AV UI profile separately on each stacking unit.

  • In the AV UI, you cannot configure the Fanout setting for a standby member of a stack of M4300-96X switches.

Workaround: Use the main UI to configure the Fanout setting.

  • When you configure the Force Multicast or Block Multicast settings for a LAG in the AV UI, the configuration is successfully applied to the switch, but the Force or Block icons do not display on the LAG port.
  • When you configure the Force Multicast or Block Multicast settings on one or several ports of a M4300-96X switch in the AV UI, the port status information (such as VLAN profiles, colors, and so on) no longer displays.
    Workaround: Refresh the AV UI page.

This firmware contains the following known issues:

  • After you upgrade the firmware from 12.0.9.x to 12.0.11.x or a newer release, when you use the main UI, and you select Routing > Multicast > Mroute Static-Multicast Configuration, the page does not display automatically.
    Workaround: After the firmware upgrade, clear your browser cache.
  • When you manually enable the Auto Negotiation through the CLI, it does not display as “Enabled” in the AV UI.
    Workaround: Configure and verify Auto Negotiation through the CLI.
  • G&D Control Center IP devices fail to link up with the switch.

Workaround: Manually set the switch port speed to 1G to establish the link.

 

Warnings:

Read and follow these warnings before updating your firmware:

  • For user passwords, line passwords, and enable passwords that are encrypted with AES in firmware release 12.0.15.7 or earlier releases, automatic migration is supported to the more secure SHA512 in release 12.0.17.6 or later releases.
  • User passwords, line passwords, and enable passwords that are encrypted with MD5 (salted) in firmware release 12.0.15.7 or earlier releases are not migrated to release 12.0.17.6 or later releases, so they must be set manually.
  • SNMPv3 MD5 and SHA-based passwords from firmware release 12.0.15.7 or earlier releases are not migrated to release 12.0.17.6 or later releases, so they must be set manually.

 

General Information:

  • The boot code remains at the existing version 1.0.0.18 in this switch firmware.
  • The process of upgrading the firmware and boot code takes about three minutes. Apply the “update bootcode” command from the command line interface. Do not switch off or restart the device during the upgrade process.
  • AppMgr is upgraded to version 1.0.5.32 in this switch firmware.
